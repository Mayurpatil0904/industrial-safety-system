# 🔷 Multi-Zone Industrial Safety System

## 📌 Overview

This project is a smart industrial safety system that combines **RFID-based access control** with **real-time environmental monitoring** using temperature and gas sensors.

The system ensures that entry is allowed only when conditions are safe, helping to prevent accidents in industrial environments.

---

## 🚀 Features

* 🔐 RFID-based access control (Zone A & Zone B)
* 🌡️ Temperature monitoring using DHT11
* 💨 Gas detection using MQ sensor
* 🚫 Interlock system to block unsafe entry
* 🔊 Buzzer alert for hazardous conditions
* 🚪 Emergency exit button for safe evacuation

---

## 🛠️ Components Used

* Arduino Mega 2560
* RC522 RFID Module (x2)
* Servo Motors
* DHT11 Sensors
* MQ Gas Sensors
* LCD Display
* Buzzer

---

## ⚙️ Working Principle

1. RFID card is scanned
2. System checks environmental conditions
3. If safe → gate opens
4. If unsafe → access is blocked + buzzer alert
5. Emergency button allows exit anytime
